GPT-SoVITS-Studio (v5turbo) 便携版
==================================

启动
----
双击 “GPT-SoVITS-Studio.exe”。

不要把 exe 单独移动出去。整个文件夹就是完整运行环境：

  resources/   Electron 应用与 Python worker
  engine/      GPT-SoVITS 运行时、v5turbo 底模、SenseVoice
  data/        配置、音色库、生成结果、日志、缓存（首次启动自动创建）

安装版
------
如果使用 GPT-SoVITS-Studio-Setup.exe 安装，安装器会自动解压文件并创建桌面快捷方式。
安装包不包含历史记录和日志，只附带示例音色 data/voices/smart_falcon.v5t。
覆盖安装时，已有 data 目录不会被删除。

首次启动
--------
第一次启动可能需要 1–3 分钟，主要是 Windows 扫描新复制的 runtime 以及
导入 PyTorch / GPT-SoVITS。进度卡会显示当前阶段和已用时间。之后启动会快很多。

使用流程
--------
语音合成：
  1. 拖入 3–10 秒参考音频。
  2. 点“识别参考音频”自动填参考文本，或手动输入。
  3. 输入目标台词，点“生成语音”。
  4. 首次生成会编译加速后端（约 15–50 秒），之后通常几秒完成。
  5. 结果可播放、打开文件夹、导出 MP3；也可以“放弃”或“放弃并重试”。
  6. 高级参数带 v5turbo 官方默认值，右上角“恢复默认”可一键还原。
  7. 采样步数是 4 / 8 / 16 / 32 四档滑块。

随机种子：
  - 种子为 -1 时也会记录本次实际使用的种子。
  - 生成完成卡片和最近生成都有“复用种子”按钮，可把种子填回参数。
  - 高级参数里的种子输入框旁有骰子按钮，点击即可设回 -1（随机）。

字幕：
  - 每次生成会在音频旁写一份 .timing.json，记录每句的真实起止时间。
  - 支持 SRT / ASS / VTT / LRC / TXT / 时间轴 JSON；格式、字数、偏移在「设置 → 字幕」里调。
  - 打开「生成时自动输出字幕」后，音频旁会直接写好所选格式。
  - 字幕文本直接用合成台词，时间来自实际音频（已去除首尾静音），不需要语音识别。
  - 长句会按标点拆成多条，切点尽量落在换气停顿上；太短的相邻句会合并。
  - 疑似静音或异常时长的句子会自动换种子重试（默认 2 次），仍异常会在卡片上提示。
  - 旧版本生成的记录没有时间轴，需要重新生成一次。

分段重新生成：
  - 最近生成每行点剪刀按钮：选一句或按住 Shift 连选几句。
  - 可以改种子、语速、温度、采样步数、topK、topP、重复惩罚，也可以改这一句的文本。
  - 先生成 1-8 个候选试听（可带前后句），确认后再替换进完整音频。
  - 替换会自动匹配前后句响度，后面的句子时间整体平移；可撤销上一步或还原原始。
  - 替换过的记录标“已编辑”，不能复用参数，但仍可导出字幕。

说话人分离（译制）：
  - 语音转文字页顶部：选视频/音频，人数选自动或 2-8。
  - 结果逐句显示说话人、起止时间和文本；可改名、改派、合并说话人。
  - 每位说话人可试听代表片段，或直接“创建音色”。
  - 依赖 CAM++ 模型（engine/models/asr/campplus，约 28MB）。

AI 连接（MCP）：
  - 「设置 → AI 连接」打开后，本机 127.0.0.1:39281 提供 MCP 服务（需要令牌）。
  - 支持 Claude Code / Claude Desktop / Codex / Cursor / opencode / Kiro / Gemini CLI / VS Code / Cline。
  - 「一键连接」自动写配置（原文件备份为 .gsv-backup）；「复制提示词」可让 agent 自己接入。
  - 关闭窗口后程序留在托盘继续为 agent 服务；agent 生成的音频会出现在「最近生成」。
  - 调用记录：data/logs/mcp.log

音色库：
  - 所有音色都是 data/voices 下的单个 .v5t 文件，文件名就是保存时的音色名。
    例如：data/voices/smart_falcon.v5t
  - 每个 .v5t 内含参考音频、音色名称、参考文本、参考语言和时长，
    直接复制给别人即可分享。
  - 合成页音色库下方有“打开音色库文件夹”“导入 .v5t”“导出 .v5t”。
  - “导入 .v5t”可以一次选择多个文件。
  - “导出 .v5t”会把当前音色另存为一份副本。
  - 旧版本按文件夹保存的音色会在下次启动时自动迁移成 .v5t，
    原 voices.json 备份为 data/voices-legacy-*.json。
  - 播放缓存位于 data/cache/voices，可随时删除，不影响 .v5t 文件。

语音转文字：
  1. 只保留 SenseVoice（中 / 英 / 日 / 韩 / 粤），更轻更快。
  2. 添加文件或整个文件夹，点“开始识别”。
  3. 结果可直接编辑，支持导出 .list / .txt。
  4. 每行结果有“发送到生成参考”，会把音频和文本直接带回语音合成页。

最近生成
--------
  - 单行列表：左侧文本，右侧直接显示波形和播放按钮。
  - “批量管理”可多选，再批量删除或导出 WAV，也可以批量导出字幕。
  - 单条/批量删除都会二次确认。
  - 输出文件按合成文本命名，只取前 15 个字符并加省略号；
    同一文本重复生成会加“（1）”“（2）”。

页面状态
--------
四个页面会保持挂载，切换页面后文本框内容、参考音频、参数、音色选择都不会丢失。

主题
----
设置 → 外观里有「彩色 / 黑白」两套风格，每套都支持深色 / 浅色 / 跟随系统：
  - 默认是「黑白 + 跟随系统」，系统深色即黑底白线，系统浅色即白底黑线。
  - 黑白：去色、直角矩形、1px 线条，无阴影 / 渐变 / 毛玻璃。
  - 彩色：原有的紫青渐变风格。

主题点击后立即预览，保存设置后持久化。

托盘与关闭
----------
  - 点窗口右上角 ×：可选“最小化到托盘”或“直接退出”，可勾选记住，设置里能改回“每次询问”。
  - 托盘图标右键：查看 TTS / ASR 状态和显存占用，卸载 TTS、ASR 或全部模型，
    开关 MCP 服务，打开输出目录，退出。
  - 最小化到托盘后，MCP 服务和已加载的模型继续保留。

显存策略（8GB 显卡）
--------------------
  TTS v5turbo       约 4.4GB 显存
  SenseVoice        约 2.1GB 显存

TTS + SenseVoice 在 8GB 显卡上也很紧。默认切换引擎会自动卸载另一个；
空闲 15 分钟自动释放；退出应用或窗口崩溃时 worker 会自行结束，显存由系统回收。

模型文件
--------
默认底模：
  engine/GPT_SoVITS/pretrained_models/s1v3.ckpt
  engine/GPT_SoVITS/pretrained_models/gsv-v5-pretrained/s2Gv5turbo.pth

训练好的 v5turbo 权重放到：
  engine/GPT_weights_v5turbo/*.ckpt
  engine/SoVITS_weights_v5turbo/*.pth

然后在“模型与显存”页点“刷新模型列表”，合成页即可选择。

人声 / 背景分离（可选，默认不附带）
  engine/models/separation/Kim_Vocal_2.onnx            人声优先，约 64MB
  engine/models/separation/UVR-MDX-NET-Inst_HQ_3.onnx  伴奏优先，约 64MB
  在“音频处理”页点“下载”即可，可选 HuggingFace 官方或 hf-mirror 镜像。

数据位置
--------
  data/outputs    生成结果与 .timing.json
  data/voices     .v5t 音色文件
  data/cache/voices 音色播放缓存
  data/logs       运行日志
  data/config.json 配置
  data/cache      模型缓存

排错
----
- 如果提示缺少模型/引擎无效：到“设置”重新选择 GPT-SoVITS 目录。
- 如果显存不足：到“模型与显存”点“卸载并释放显存”，或点顶栏“全部卸载”。
- 如果 SenseVoice 结果没有标点：可直接编辑。
- 未签名 exe 可能触发 SmartScreen；自用可放行。
- 如果窗口闪退且日志里出现 “GPU process exited unexpectedly”：属于系统环境导致 GPU 子进程无法启动，
  已在程序内默认使用 in-process GPU；如需恢复 Electron 默认行为，设置环境变量 GSV_SEPARATE_GPU=1。
- 导出字幕提示没有时间轴：该记录由旧版本生成，重新生成一次即可。
